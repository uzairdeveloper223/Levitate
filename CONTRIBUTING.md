# Contributing to Levitate

Keep changes small and native to each platform. Motion processing belongs on Android; Linux receives bounded input commands. Preserve low idle resource use and the local-only connection model.

Before opening a pull request, run the Linux protocol/server tests and Android motion tests and lint. Include real-device or native-window screenshots for UI changes, in light and dark themes. Avoid adding a browser runtime or continuously redrawing the desktop UI.

Report hardware, Android version, sensor name, distribution, compositor and network arrangement for gesture bugs. Do not include active QR codes, tokens, private keys, or sensitive logs. Start with an issue for changes to the wire protocol or input permissions.
